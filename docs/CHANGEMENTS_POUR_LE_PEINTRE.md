# Ce qui a changé sur votre site (en bref)

Petit résumé, sans jargon technique, de ce qui vient d’être mis en place pour vous.

---

## 1. Le dossier de presse fonctionne enfin

Avant, le bouton « Télécharger le dossier de presse » ne faisait rien.

**Maintenant :**
1. Allez dans le Studio → **Paramètres du site**
2. Uploadez votre PDF dans **Dossier de presse (PDF)**
3. Publiez

Le bouton apparaît sur le site et permet de télécharger le fichier.  
S’il n’y a pas de PDF, le bouton est simplement caché (plus de lien cassé).

---

## 2. Vous pouvez mettre des vidéos dans vos textes

Dans les cours (enseignement), l’histoire de l’art, les expositions, les « expositions à voir », etc. :

1. Ouvrez le document dans le Studio
2. Dans le **Contenu**, ajoutez un bloc **« Vidéo »**
3. Collez le lien YouTube ou Vimeo
4. Publiez

La vidéo s’affiche au milieu du texte, pour appuyer une explication.

**Astuce :** il existe aussi un champ « URL vidéo (bas de page) » : ça met la vidéo **en bas** de la fiche. Pour illustrer un passage précis, préférez le bloc **Vidéo** dans le Contenu.

---

## 3. Les images peuvent être entourées par le texte

Avant, une image mise au milieu d’un texte prenait souvent toute la largeur, avec de grands espaces.

**Maintenant**, quand vous ajoutez une **Image** dans le Contenu :
- choisissez **Flottant gauche** ou **Flottant droite** → le texte passe à côté de l’image
- choisissez **Centré** / **Pleine largeur** → l’image reste seule sur sa ligne

Sur téléphone, l’image se remet automatiquement en dessous du texte (plus lisible).

Dans le Studio, un petit schéma vous montre à peu près comment ça sera disposé (ce n’est pas exactement comme le site, mais ça aide).

---

## 4. Les performances peuvent avoir un texte

Pour chaque vidéo de performance, vous pouvez maintenant écrire une **description** (lieu, contexte, date…).

Elle s’affiche sous la vidéo. Si le texte est long, le visiteur peut cliquer « Voir plus ».

---

## En une phrase

Vous pouvez **mettre des vidéos** dans vos cours et expos, **faire flotter les images** à côté du texte, **ajouter un texte** sous les performances, et **proposer votre dossier de presse en PDF** vous-même depuis le Studio.

Pour le détail pas à pas : voir aussi le fichier [MODE_EMPLOI.md](MODE_EMPLOI.md).
